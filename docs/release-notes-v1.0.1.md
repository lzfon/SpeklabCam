### 这一版改了什么

**1. 日期后背不再印成「导入那一天」（bug 修复）**

当天导入的照片，日期后背印的是今天而不是实际拍摄日期；必须把日期后背关掉再打开一次才显示正确。
根因是导入时先给一个临时参数对象填了拍摄日期，紧接着整个对象被「恢复侧车 / 新建默认参数」替换掉，
填进去的日期跟着丢了，字段空着就退回系统当天。现在填日期挪到参数定稿之后，「重置全部参数」同样补填；
EXIF 里没有拍摄时间时退回相册记录的 `DATE_TAKEN`，两者都读不到才用系统当天——**绝不拿文件修改时间冒充拍摄日期**。
关掉再打开这个「 workaround」从此不需要了。

**2. 片边随机身份重做：相机种子 / 过片种子 / 帧号**

- 相机种子、过片种子：滑轨 **0-999**，默认 0。**0 = 这一张在 1-999 里随机一套**（拖回 0 再随机一次）；
  手动停在 1-999 就按这个数输出，想复刻同一颗机身的磨损就填同一个数。
- 帧号（这一版把「画幅编号」这个名字改回「帧号」）：滑轨 **0-36**，默认 0。**0 = 这一张在 1-36 里随机一号**；
  手动停在 1-36 按设定输出。
- **删除**原来的「按导入数量整卷 36 帧自动递增」与「手动帧号开关」两套逻辑。
- 随机到的那一号会跟照片一起存进侧车，所以预览看到什么、导出就是什么；「同步设置到其它照片」不再搬运这三号。

**3. 批量导出的片边连号，改成导出页的一个开关（默认关闭）**

导出页（批量）在「导出所选照片」按钮上方新增开关**「带片边照片按帧号顺序导出」**：

- **关闭（默认）**：点导出直接按每张照片自己的帧号与种子输出，**不统计、不改写任何参数**。
- **打开**：点「导出所选照片」才先统计这批里有多少张开了片边，弹框确认——
  带片边的按勾选顺序从 01 开始连号，排到 36 回到 01 继续，照片够多就循环往复；不带片边的不参与；
  同时这些照片的**相机种子与过片种子强制按 1 输出**（整批同一颗机身、同一次扫描，接起来的片边才连贯）。
  确认后点「开始导出」才真正改写各照片自己的参数并开始导出，点「取消」什么都不改。

**4. 导出页四栏默认全部收起**

文件格式 / 保留信息 / 导出配方 / 高级设置 进页面即为收起状态，点标题展开，收起时标题右侧直接显示当前取值；
四个格式按钮仍常显在栏头外面，切格式不用先展开。

**5. 配方与这三项的关系收紧**

相机种子 / 过片种子 / 帧号属于**单张照片自己的身份**，不随任何配方传递（仓库里 8 支自带配方也确认一个 `overscan_*` 键都没写）。
这一版在「套用我的配方」的路径上再显式把这三项复位为 0，清掉旧版本按整卷预排留下的非 0 残留值。

### 已知限制

- 只发布 arm64-v8a（x86_64 仅用于模拟器调试）。
- **已经导出过的旧成片不会自动追改日期与帧号**（那些字是导出那一刻印进画面的），需要重导一次。
- RAW（`.dng`）的日期取数走 EXIF→`DATE_TAKEN` 两级兜底；个别机型相册没记 `DATE_TAKEN` 时仍可能落到系统当天，
  此时日期框下方会提示「照片未记录拍摄日期，请手动输入」。
- 关闭胶片模拟的自定义配方仍会套所选胶片的颗粒，属引擎既有行为。
- 本 fork 未修改引擎 C++/Vulkan 源码；从源码自编译引擎需自行配置 `spektraEngineDir`。
