### 这一版改了什么

**1. 首页与底栏重排**

- 底栏固定三格：**图库 / Speklab / 观片**；首页右上角齿轮收纳导入、参数说明、设置、关于。
- 首页有两种显示方式（设置 → 界面 → 首页显示）：**预览框 · 当前照片**（默认）与**宫格 · 图库照片**（两列错落，长按勾选可批量放入工作台）。
- 预览框这一格**冷启动不再空着**：以前必须先进一次图库页才会显示，刚打开 App 时明明工作台有活却提示「打开系统相机拍摄」。
  现在直接读工作台存档里那张当前照片——渲染过的用成品效果图，没渲染过的取原片，**点一下就是继续显影**，恢复整个工作台。
- 悬浮簇：左侧「智能配方」显示当前所用配方名，右侧导入与拍摄两个动作。

**2. 编辑页菜单与控制条**

- 参数菜单改成三层：一级药丸选类别、二级选分组、三级才是参数本身；齿轮里的菜单项与页面同级，不再套两层折叠。
- 控制条一排到底：**工作台 / 拍摄 / 调整预览大小 / 撤销 / 重做 / 导出**，工具菜单图标是自绘线框工具箱。
- 照片条与图库「放入」条并入计数行；多选态下整条可点；计数写成「N 张/共 N 张」，恢复入口收成「恢复工作台 N 张」。
- **工作台闲置后不再自动收起**（默认关）。想要的人可在设置里打开「工作台自动隐藏」，等待秒数 3–10 秒照旧生效。
  上一版这条默认是开的，收起后照片条容易找不到，这一版把默认改回来。
- 关于页与参数说明里凡是与上述默认值矛盾的表述同步改正；老设备上被手动改过的三项（自动隐藏、直方图、首页显示）
  做一次性对齐，之后完全尊重你自己的选择。

**3. 直方图（这是"看着像坏了"的那处）**

- 刻度由线性改为**开根号**。线性刻度下一个主峰就能占掉两三成高度，其余 255 个桶被压成贴底的一条线，
  看上去像直方图没画；改完红绿蓝三通道的分布正常可见，0 号桶的尖峰也不再吃掉整张图。
- 顺带补了「数据不足 256 桶直接不画」的兜底，堵住一条可能越界崩溃的分支。
- 默认显示直方图，设置里可关（关掉后预览左上角更干净）。

**4. 缩略图直接显示成品效果图**

- 首页宫格、照片图库、观片台里，凡是**在编辑页渲染过**的照片，格子直接显示成片（齿孔、片边、日期、胶片名都在），
  不再是原片。磁盘缓存长边 512 的 WebP（quality 85，键 = 照片身份 + 参数修订号，总量 64MB LRU）。
- 修掉三个真实故障：
  - **快速连翻不再丢写**：以前等 600ms 去抖再落盘，切照片时那份待写帧被直接取消，那张永远没效果图。
    现在静帧一到就先复制一张 512 小图排队，后台一张一张串行写。
  - **不再出现空白格**：换版时以前是"先删掉旧图再取新图"，而取图入口挂在照片身份上不会重新触发，于是格子空着。
    现在新图到手才替换。
  - **滚出屏幕期间改了参数，回来不会赖着旧效果图**：失效记账写错位置（位图还在缓存里却把修订号记录删掉了），已修正。
- 图库与首页的原片解码由 384 提到 **512**，与渲染过的成品同一档清晰度；以前同一屏里"渲染过的清楚、没渲染的糊"两档明显。

**5. 数据安全：单击一格不再清空工作台**

- 以前单击首页或图库里的某一张，会**把整个工作台换成这一张**，并且立刻覆盖存档——
  10 张的工作台点一下就只剩 1 张，且找不回来。现在：
  - 这张本来就在工作台上 → 只切换当前照片，其余不动；
  - 这张不在工作台上 → 先问一句：**「追加至工作台」**（加到末尾，原来那些一张不动）/
    **「新建工作台（替换当前 N 张）」**（工作台只留这一张，原来的照片与参数仍在图库里）/ 取消。
- API 29 以下的系统不再白弹一次「媒体位置」权限（这权限是 Android 10 才有的，问了也只会被拒）。

**6. 界面收纳与代码体检**

- 低使用率入口（数字中间片、DI TIFF、软打样、高清预览、效果细节检查）从界面撤下，**实现代码全部保留**，
  不占界面；需要恢复入口随时可以。
- 全量体检：Android Lint 全量 + 编译告警 + 孤儿资源/孤儿函数扫描后，删掉 10 项无引用资源、
  9 个零调用函数、以及一条"有存储、有读取、但界面永远改不动"的偏好链路（菜单互斥）；
  两条 StaticFieldLeak 与七条 UsableSpace 复核为误报，未动。安装包 52,935,945 B，比 1.0.2 大 71,659 B
  （新增效果图缓存等功能的净增，删掉的死代码与死资源抵掉了一部分）。

### 已知限制

- 只发布 arm64-v8a（x86_64 仅用于模拟器调试）。
- **效果图缓存在系统缓存目录**：系统在空间紧张时回收、或你在「应用信息」里点「清除缓存」之后，
  格子会暂时回到原片；重新进编辑页渲染一次即恢复，**不影响导出的成品**。
- 首页预览框这一格尺寸较大，用的是 512 长边缓存，放大后**略有软化**；要更锐需要为它单独存一份 1024，本版未做。
- **图库列表与照片信息里显示的 DNG 尺寸仍是内嵌预览的尺寸**（读尺寸走的是位图解码），不影响导出成品；
  这一处仍是上版遗留，留待收口。
- **已经导出过的旧成片不会自动追改**：RAW 判定、日期与帧号都是导出那一刻印进画面的，需要重新导出一次。
- RAW（`.dng`）的日期取数走 EXIF→`DATE_TAKEN` 两级兜底；个别机型相册没记 `DATE_TAKEN` 时仍可能落到系统当天，
  此时日期框下方会提示「照片未记录拍摄日期，请手动输入」。
- 「智能配方 / 复制配方到多张」仍只把参数应用到当前一张，其余照片需逐张打开渲染（既有边界，本版未改）。
