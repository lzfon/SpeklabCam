## 一、先说清楚三件事

1. **配方不内置在安装包里。** App 出厂不带任何配方，我的配方列表一开始是空的。
   想要这 8 支，就把 JSON 下载到你手机，然后在 App 里导入：**首页 → 智能配方 →「增加我的配方」→ 弹窗底部「导入配方」**；
   编辑页里扳手菜单的「编辑配方」打开的是同一个弹窗。
2. **影片名字只是"这段影调长什么样"的描述。** 本文件与配方 JSON 里**没有任何剧照、截图、海报或影片画面**，
   那些内容的版权归原影片权利人所有，不属于本仓库的开源范围，也不要往仓库里传。
3. **材料（胶片 + 相纸）已经写在配方里。** 导入后套用会自动切到对应的胶片与相纸，不需要你手动选配；
   但套用的前提是**你的 App 里有这个胶片/相纸的档案**（来自上游 spektrafilm 素材，安装包已自带）。

> 每个参数怎么理解、滑轨在界面哪一格，见 [`docs/help-params.md`](help-params.md)。本文只讲每支配方"为什么这么调、什么场景好用、容易翻车在哪"。

### 导入后会覆盖什么

配方包含这几组：材料（`material`）、解码白平衡（`decode`）、胶片与乳剂（`film`）、放大机（`print`）、
影调（`light`）、色彩（`color`）、暗角（`vignette`）。

**不包含**：曲线（`curves`）、几何与裁剪（`geometry`）、片边与日期后背（`frame`）、导出设置（格式/尺寸/色域/文件名）。
也就是说，套用配方不会动你的裁剪和曲线，也不会改你的导出习惯；片边和日期你想加就自己加。

## 三、逐支说明

### 1. 花样年华·暗红浓绿

**影调依据**：旗袍、走廊、翡翠绿墙壁、钨丝灯。整体是"暖底 + 高饱和 + 实黑"，红色浓但不炸，绿色偏冷墨绿，
高光压得住，暗部是黑的而不是灰的。

**为什么这么调**

- 500T + 2383：灯光卷做底，正片工艺出高密度与厚暗部。
- 中央重点测光、欠 1/3 档：保住窗光和灯罩的高光，负片欠一点暗部更实。
- 打印曝光 1.06 + Y +0.18：黄滤色片吸蓝，画面往暖里走，同时高光更"厚"。
- 对比 16、高光 −16、黑点 +8：中间调不动，两头压实，是"老胶片放大"的密度感。
- 色温 +0.16、饱和 +14，红带饱和 +12、绿带色相 +8：红更浓、绿更冷墨，这是这支配方的辨识度所在。
- 暗角 16/60/82：只压边角，室内场景不显 artificial。

**适用**：室内灯光、老街区、走廊、餐厅、旗袍/复古服饰、夜间窗内拍人。
**不适合**：大日光风景、雪景、需要干净白墙的商业片——白墙会偏米黄。

**避坑**

- 拍**大面积白墙或荧光灯（偏绿）**时，绿带 +8 的色相偏移会把绿色推得更冷，觉得过了就把绿色相回 0。
- 原片高光已经过曝的话，"高光 −16 + 黑点 +8"会让画面发闷，先减对比到 10 左右。

**可微调**：`饱和度` +14 是最容易过的一格，拍小孩、拍肤色建议降到 +6；想更像戏里那种"红墙"，把红带饱和度加到 +18。

### 2. 重庆森林·酸绿夜色

**影调依据**：夜街、荧光管、自动贩卖机、钠灯橙。核心是**又酸又绿的荧光感 + 高饱和 + 强颗粒**，
中间调偏冷、暗部压青。

**为什么这么调**

- 保护高光测光、欠 2/3 档：夜景里霓虹灯和橱窗全是易过曝的小面积高光，先保住它们。
- 对比 24（本组里最高之一）、黑点 +10：夜街要有硬反差和死黑底，才撑得住霓虹。
- 色温 −0.10、色调 −0.12（往绿）、饱和 +24：绿被推到"酸"的程度。
- 绿带饱和 +20、青带 +6、橙带 +14：绿和橙同时拉高，形成典型的霓虹撞色。
- 光晕 2.4、纸面光晕 3.0、颗粒 1.4：灯周围要"化开"，强颗粒给夜店街头的粗粝感。
- 暗角 20/52/76：范围偏内（52），羽化偏硬（76），镜头感更像广角街头。

**适用**：夜市、便利店、车内霓虹、雨天街面反光、酒吧门口。
**不适合**：人像（饱和 +24 与色调 −0.12 会让脸发绿）；白天风景。

**避坑**

- **肤色发绿**是最常见的翻车点：拍人请先把色调从 −0.12 拉回 0，橙带明度 +4 保留即可。
- 原片本身是钨丝灯直出的暖图，再叠这一套会偏黄；这种片子建议改用第 1 支。

**可微调**：想更"脏"一点，颗粒 1.4 → 1.6；想更清爽，对比 24 → 18，饱和 24 → 16。

### 3. 英雄本色·钢蓝烟幕

**影调依据**：夜战、烟雾、枪火、只保留血色红。暗部是**钢蓝**，高光是**钨丝暖**，整体**降饱和**，
反差硬、密度厚。

**为什么这么调**

- 相纸换成 **2393**（高反差正片纸基）：这是这支配方的骨架，直接给出硬反差和厚黑。
- DIR 0.85（低于正常 1.0）：削弱成色剂耦合的边缘效应，色彩更"平"更冷，接近旧胶片冲洗偏软的那层灰。
- 饱和 −16、vibrance −8，只把红带饱和度加回 +10、明度 −8：满画面压色、唯独血色红留着并压暗，是"血"的味道。
- 绿带 −18、黄带 −14：把烟、木、墙这些"脏中间色"抽掉。
- 黑点 +12、亮度 −3、高光 −14：暗部压实、中间整体下沉，烟雾有厚度而不是灰雾。
- 色温 −0.10 + 阴影区分离色调 −16/+2：暗部压青蓝，高光区 +12 暖，冷暖分离。

**适用**：夜景人像（男人味/硬光）、车库、巷道、烟/雾/火光、老式建筑内部、雨夜车窗。
**不适合**：想拍明快色彩的一切——它会先把颜色抽干。

**避坑**

- **2393 与 2383 的观感差别很大**，如果套用后你手机上被自动切成别的相纸（材料不可用），效果会散架；套完先看材料一栏是不是 500T + 2393。
- 压黑很狠（黑点 +12 + 亮度 −3），暗部细节多的场景（暗角里要看得见东西）请把亮度回到 0。

**可微调**：嫌太冷就只动 `色温`（−0.10 → −0.04），别动分离色调；想更"血色"把红带饱和度加到 +16。

### 4. 堕落天使·青紫霓虹

**影调依据**：广角、夜店、青紫暗部 + 品红霓虹、强光在镜头上化开。整套里最"怪"的一支，
也是唯一换胶片的一支。

**为什么这么调**

- 胶片换成 **CineStill 800T**（无防光晕层），并且**光晕模型用背反射（`halation_model_version: 2`）**：
  这支配方的红/品红光晕是按片基反射的物理几何算出来的，跟实拍 800T 的灯晕最接近；其余 7 支都是经典模型。
- 对比 22、黑点 +14（本组最狠）、暗角 24/46/70（强度最大、范围最靠内、羽化最硬）：
  仿超广角夜拍的强边缘压暗和死黑。
- 色温 −0.16、青带 +10、紫带色相 −6/饱和 +12、品红 +16：暗部青、灯罩品红，两段撞色。
- 预闪 0.005：极轻的一次底片预闪，让暗部不至于死成纯黑、保留一点可辨层次（不是加亮度）。
- 颗粒 1.5：高感卷 + 大颗粒，故意留粗。

**适用**：夜店/KTV 门口、霓虹招牌、雨中车窗、广角压得很低的人像、任何"灯光直接进镜头"的画面。
**不适合**：需要干净暗部或精细色彩的（风景、静物、棚拍）。

**避坑**

- **最容易过曝**：800T + 强预闪 + 大量光晕，原片过曝时高光会一坨化开。请严格按配方给的"保护高光 + 欠 2/3"拍，
  或事后把 `print_exposure` 从 1.00 降到 0.94。
- 暗角 24 很凶，构图主体靠边时会明显变黑；嫌重降到 16/56/78。
- 这支对**人脸**不友好（品红 +16），拍人建议把品红饱和度回到 +6。

**可微调**：想要更"电影"就加 `halation_boost_ev`（2 → 3）；想要更冷就 `tint` +0.08 → +0.12。

### 5. 阿郎的故事·褪色尘土

**影调依据**：赛道、海边、硬日光、褪色海报感。特征是**抬黑发灰、对比极低、土黄橄榄**，
看着像放了十几年的彩色放大片。

**为什么这么调**

- 胶片换成 **250D**（低感日光卷）+ 均衡测光 + **曝 1/3 档**：唯一一支正向曝光补偿的配方，
  目的是让暗部多收到光，才有"抬得起来发灰"的余地。
- 对比 **4**（本组最低）、黑点 **−10**（把黑端整体抬灰）、预闪 **0.012**（本组最大）：
  三件事合起来做"褪色"——靠物理手段减反差、抬暗部，不是靠加亮度。
- Y +0.22（滤色最多）+ 色温 +0.12：土黄橄榄的来处。
- 绿带 −14、青带 −12、蓝带 −10，且各带明度 +2：冷色被抽掉并轻微提亮，旧海报的"青色褪掉只剩黄红"。
- DIR 0.70：色彩分离更弱、更糊更旧。颗粒 1.00、光晕 1.2：低调，不抢褪色感。
- 暗角 8/68/90：几乎看不出，只是让视线收在中间。

**适用**：正午/下午的户外、老-road、摩托车、工地、海边、废土、任何想"旧一点、脏一点"的日光场景。
**不适合**：夜景（抬黑会把暗部抬成一片灰雾，画面立刻发闷）。

**避坑**

- **不要在晚上用**，这是这支配方最大的误用点。
- 想要更浓的旧感可以，但别同时把 `黑点` 和 `预闪` 再往一边推，两者叠加会得到一张没有重色的灰片。

**可微调**：觉得太灰，`黑点` −10 → −4；觉得不够黄，`滤镜 Y` +0.22 → +0.30；想更褪色，`对比` 4 → 0。

### 6. 天若有情·冷暖夜雨

**影调依据**：夜雨、码头、机车、湿路反光。冷暖分离最讲究的一支：
**青蓝暗部 + 暖橙主光**，皮肤要留得住，雨水反光要亮。

**为什么这么调**

- 中央重点测光、欠 1/3：主体（人/车）优先，路面高光交给测光保护。
- 对比 18、高光 −12、阴影 +2：湿路的反光要透，但不能糊成一片。
- 阴影区分离色调 −16/+2、高光区 +14/+2：这是冷暖分离的主体做法——暗部压青、亮部加暖，中间调基本不动（−4/+4）。
- 红带 −6/+10、橙带 +4/+10/+2、绿带 −8：肤色和机车烤漆保住，绿脏色抽掉。
- 光晕 2.2、散射 0.9、提升 1.5EV、纸面光晕 2.0、预闪 0.004：雨夜灯光要"化"但不炸。
- 饱和 +8、vibrance +6：克制，不抢戏。

**适用**：雨夜、雨后街、码头/江边、机车/汽车、双人夜景、有路灯的土路。
**不适合**：正午硬光（高光 −12 + 阴影 +2 会让日光场景显得平）。

**避坑**

- 原片如果是**手机自动HDR的夜雨**，暗部已经偏亮，阴影 +2 会让画面发浮；把它降到 0。
- 拍纯风景（没有人/车做暖色锚点）时冷暖分离会显得整片发青，加 `色温` +0.04 找回一点。

**可微调**：想更冷峻 → `色温` −0.08 → −0.14；想更暖情 → 高光区色温 +14 → +20。

### 7. 山河故人·冰河烟花

**影调依据**：冰河、夜、火堆与烟花、一件红大衣。画面**整体压到很冷的青黑**，
只让红色和火光成为唯一暖源。

**为什么这么调**

- 色温 **−0.18**、饱和 **−18**、对比只有 **8**：整个世界的颜色被抽走大半，反差也放平，冷而不动声色。
- 红带饱和度 **+18**、明度 +2（本组对红色最"偏心"的一支），橙带 −6 且明度 +6，绿带 **−20**：
  红大衣/火光单独跳出来，植被和肤色都退到背景里。
- 光晕 **2.8**（本组最大）、提升 2EV、散射 0.8：火和烟花要打出大面积扩散；暗部靠 2383 的密度压成青黑。
- 高光 −16、黑点 +4：烟花核心不会烧成纯白，河滩暗部保持有底。
- 颗粒 1.10、暗角 10/64/88：温和，重点在冷暖而不是粗粝。

**适用**：雪景/冰面/河滩的夜、篝火与烟花、冬夜户外、大面积冷调环境里有一个暖色主体。
**不适合**：多人合影、需要正常肤色的场合（绿带 −20 与饱和 −18 会让人显得病气）。

**避坑**

- **拍人务必抬肤色**：把橙带饱和度从 −6 提到 +6，`饱和` 从 −18 提到 −8，其他都不用动。
- 烟花照片如果本身已严重过曝，光晕 2.8 会把整片天空糊住；降到 1.8，或把 `print_exposure` 1.06 → 1.00。

**可微调**：想要更"青"，`tint` +0.04 → +0.10；想要红色更抢，`绿带饱和度` −20 → −26。

### 8. 山河故人·1999县城冬日

**影调依据**：1999 年的县城、冬天、硬阳光、土路与砖墙。冷阴影 + 暖肤色，
红大衣、标语、砖色要跳出来。比第 7 支更亮、更"日光"、更纪实。

**为什么这么调**

- **250D** + 均衡测光 + 欠 1/3：低感日光卷给细颗粒与干净高光；轻微欠曝保留北方冬天的硬光质感。
- 亮度 +4、白点 +6、黑点 −2：整体明亮、高光透亮、暗部略松——纪实片的通透感。
- 对比 14、高光 −10、阴影 +6：两头都收一点，中间调结实。
- 色温 +0.08、高光区分离色调 +14：阳光是暖的；阴影区 −12/+2：影子是冷的。这就是"冬日硬阳光"的核心。
- 红带 +14、橙带 +8/+4、黄带 +6：砖、标语、皮肤都在暖色一侧被加强；绿带 −6 压住杂色。
- vibrance +10 而饱和只 +12：颜色多但不出格，肤色优先。
- 颗粒 1.05、光晕 1.6、暗角 8/66/86：全部克制。

**适用**：冬天的日光场景、县城/乡村街巷、Old 建筑、集市、人像纪实、雪面反光。
**不适合**：夜景（亮度 +4 与白点 +6 会让暗部发灰）。

**避坑**

- 雪景里如果原片已偏蓝，`色温` +0.08 会显得脏；雪天建议 +0.12～+0.16，同时把 `高光` 从 −10 收到 −6。
- 正午顶光下拍人，额头会偏橙；把橙带饱和度从 +8 降到 +4。

**可微调**：想更像 90 年代旧照片 → `滤镜 Y` +0.10 → +0.24，`对比` 14 → 10，`黑点` −2 → −6。

## 四、几支一起用的顺序建议

按"先定胶片性格，再定冷暖强度"来选：

1. 白天日光、要旧 → **5 阿郎**；要干净纪实 → **8 1999县城冬日**
2. 夜里、要霓虹撞色 → **2 重庆森林**；要青紫广角味 → **4 堕落天使**
3. 夜里、要冷暖分离而非撞色 → **6 天若有情**；要钢蓝硬派 → **3 英雄本色**
4. 室内暖光、要浓红墨绿 → **1 花样年华**
5. 冷调环境 + 单一暖色主体 → **7 冰河烟花**

同一卷片子（同一个拍摄 session）建议只用一支，别交替混用——出片会显得不成组。
