# CineStill 800T：PC 与 Android 同源对照

日期：2026-11-15。Android 版本保持 `0.1.6`、versionCode `7`。

## 本轮结论

使用用户提供的 `DSC_5099.NEF`，对正在运行的 PC 正式包、对应源码及 Android 实际 Release 原生库进行了对照。**相同参数、相同 6064×4040 尺寸下，CineStill 原生显影链路已基本一致**，sRGB 与 ProPhoto RGB 两组完整 U16 栅格的最大逐通道差异均为 1。

实际发现并修复了两项胶片选择入口差异：

1. PC 主动选择胶片时跟随该胶片声明的相纸；Android 此前只检查相纸是否兼容，会将 Portra Endura 沿用到 CineStill，未切到 Vision 2383。
2. Android 对已选中的胶片过早返回。旧记录若保存了 CineStill 与经典光晕模型，再次点击同一胶片不能显式选择背反射模型。

没有修改材料测量数据、PSF 系数或加大光晕来追截图。原片、旧编辑和历史项目不会在载入时静默改写；**主动重新点选**胶片才应用本次对齐规则。

用户未确认手机旧图的完整参数。入口差异已直接复现，但不能仅凭旧 JPEG 唯一反推出其相纸、光晕、后期和导出设置。

- 安装包构建清单 commit：`2ca735ad60a998e925bf346f57d80012bdb5c6bf`；该对象存在于本地 `SpektraLab` Git 仓库，按 commit 提取源码核对，未切换分支或修改原项目。
- PC 使用独立启动的正式 `spektralab-host.exe`，NVIDIA RTX 5060 Vulkan；没有操纵或重新打开用户当前 PC 编辑窗口。
- Android 使用 API 37、x86_64 模拟器及实际 Release 原生库。ARM64 编译通过，不等于 ARM 手机测试。
- 输入 SHA-256：`cafd8050d216fd08923eb972221c2011c2a4d39cda33efb6b0ed39e2a77ede3b`。用户本次文件、PC 保存记录指向的原片，以及实际推入模拟器的测试文件摘要一致。

## 参数不能只对齐胶片名称

从 PC 保存记录读取到的该照片设置如下：

| 项目 | PC 保存值与本轮对照 |
| --- | --- |
| 胶片 | CineStill 800T，继承 Vision3 500T 测量数据，无防光晕层 |
| 相纸 | `kodak_2383`，Vision 2383 |
| 测光 | 自动、balanced；手动曝光补偿为 0 |
| 相机白平衡 | As Shot；5120 K、+15.7 是显示的相机白平衡信息，不作为额外后期色温再次叠加 |
| 胶片画幅 | PC 按 135 短边 24 mm 和原片宽高比得到长边约 36.023762 mm；严格同参测试显式传入对应值 |
| 光晕 | 物理背反射、面积 1、散射 1、增强 0、高光余量 4 EV |

| 后期 | PC 保存记录中的基础调色与曲线为中性 |

PC 界面的总曝光读数不能直接当作额外手动补偿重复输入。仅名称相同、相纸或光晕模型不同，最终成片不会是同一个配方。

## 核对了哪些实现

对照实际 PC commit 的 `params.cpp`、`pipeline.cpp`、`halation_psf.hpp`、RAW 解码、视图输出及 Vulkan shader，并检查 Android 的 CMake overlay 和实际编译输入。

- RAW：AHD、线性 ProPhoto RGB、相机白平衡、关闭自动提亮的完整输入链路；本样本经过此前 LibRaw 升级后没有出现原生显影像素级偏色。
- 场景：balanced 测光、曝光、整帧高光峰值与 4 EV 高光余量节点。
- 胶片：CineStill 别名、Vision3 测量数组、基础材料中性滤色表、DIR、乳剂散射与四分量背反射。
- 相纸与扫描：Vision 2383、冲印曝光与滤色、扫描、色域处理和传递函数。
- 随机效果：PSF 头文件、四份颗粒及眩光场 shader 的文本与实际 PC 对应源码相同，文件换行方式不同；没有把不同随机实现或不同渲染尺寸的像素当作确定性参考。
- Android 的导出所有权、带状 FIR 和取消适配保留。与上一批包相比，六份原生库、102 项非 DEX 基线素材和 Manifest 逐字节一致；这次生产代码只调整 `EditorViewModel.selectFilm` 的入口策略。

## 修复后的选择规则

主动点选胶片时先选择其声明且兼容的目标相纸；没有可用目标时才回退当前兼容相纸，再回退其他可用相纸。CineStill 明确使用背反射模型。直到目标胶片、目标相纸、目标模型全部相同时才按无变化返回。

因此，再次点选旧 CineStill 记录可以显式修复相纸或模型；已处于标准组合时重复点击不增加显影。其他用户参数及高光余量偏好保留，不擅自抹掉手工后期。载入旧记录、恢复项目和导入预设继续保持其已保存的自定义相纸和旧模型。

修复前的回归失败原样保存在 `.tmp/pc-parity/selection-red-run.log`：CineStill 预期 `kodak_2383`，实际保留 `kodak_portra_endura`。修复后同一断言及全部已声明兼容材料目标、CineStill 同款重复选择、无照片不解码/不渲染均通过。

| sRGB，6064×4040 | 73,495,680 | 1 | 0.00217145 |

门槛固定采用归一化误差 `3e-5`，没有为了通过放宽；同尺寸 alpha 全部保持不透明。用可复用脚本独立重启 PC host 再生成一遍参考，结果再次通过。关闭颗粒与眩光只用于去除随机量，正式产品默认效果没有因此关闭。

最终候选的 15 组、27 条仪器记录全部通过，另有上述两项独立原生整图对照。涵盖：

- PC 材料选择规则，CineStill 物理/经典/余量、无防光晕层、关闭/零强度、不合法原子更新、旧记录与历史兼容。
- 真正的胶片卡片交互、原图按住和分屏、PNG/JPEG100/TIFF16 单张与批量、取消恢复、胶片切换期间最新调色保护。

## 尺寸、性能与验收边界

本次 PC 图片是 6064×4040，手机图片是 2560×1705。颗粒会受到输出采样尺度影响，RAW 的半尺寸预览及先缩小再显影也不是“全尺寸显影后再缩小”的同一流程。比较模型应先固定输入、参数和输出尺寸。本次没有把默认预览改成全尺寸，以免重新引入大图内存峰值和交互卡顿。

模拟器本轮 1600×1200、每项预热一次再测三次的中位数：模型 182.92 ms、余量 214.24 ms、面积 161.71 ms、散射 189.72 ms、增强 169.85 ms、胶片切换 163.46 ms。24MP TIFF 首次 9412 ms、缓存 1016 ms。它们是本轮场景采样，未做新的交错全参数基准，不能承诺所有手机零延迟回退。

PC 的 ProPhoto 工作空间视图转换、任意非中性后期参数及随机颗粒不是本次两组原生整图相等的验收结论。单独比较 PC 原生 sRGB 与其 ProPhoto→sRGB 视图，在本样本确定性数据中平均约差 1.97 个 8 位单位，少数饱和高光差异更大；这些不同表面不应混称为同一路径。F17 的完整工作空间/后期一致性、ARM 真机、更多场景和此前所有未完成范围保留，不因本次测试标为已验收。

## 重现与本地包

新增两个显式工具，均不改动源照片或 PC 编辑记录：

```powershell
python tools/capture_pc_render_reference.py --pc-root <PC便携包目录> --source <原片> --params <PC平面wire参数JSON> --output <全新参考目录>
python tools/verify_pc_render_parity.py --pc-dir <参考目录> --android-dir <仪器测试拉回目录> --source <同一原片> --report <结果JSON>
```

采集参数必须显式关闭随机颗粒和眩光。独立比较工具需要 NumPy；参考与原片摘要、尺寸、完整 RGB 通道及 alpha 都会检查。Android 仪器入口 `pc-parity` 需要显式提供名为 `pc-parity-DSC_5099.NEF` 的测试原片；`pc-selection` 不需要读取任何用户照片。无输入时直接失败，不跳过。

安装包归档为 `app/release/v0.1.6-pc-aligned/Theia-v0.1.6-universal.apk`，当前 `app/release/Theia-v0.1.6-universal.apk` 同步到相同文件。56,330,295 字节，SHA-256 `2458529fca872df72cafc572dde77a33c33fe1df9de12994cd6baed640a34dcf`。保留之前的 LibRaw 与观景台修复，原更新证书、V1/V2/V3 和 16 KiB 对齐通过。没有提交、推送或发布。

核对手机时可重新点选 CineStill，确认 Vision 2383、背反射与高光余量 4 EV；保留相机 As Shot 白平衡，确认没有额外后期，再用与 PC 一致的尺寸比较。重新点选不会自动清除用户手工后期或恢复所有参数。
