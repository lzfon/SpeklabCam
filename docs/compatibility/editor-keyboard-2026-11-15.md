# 编辑器键盘弹出后退出输入修复

日期：2026-11-15。基线：`f38856d`。用户反馈修改日期后背时，输入法刚打开就退出输入状态。

## 原因

`EditorScreen` 原先以扣除工具栏、导航和 IME 后的内容区域宽高判断 `landscape`。手机仍竖直摆放，键盘却可能让剩余高度小于宽度，触发从上下布局切到双栏布局。`AdjustmentWorkspace` 和 `EditorPanel` 属于不同的组成路径，日期参数随之被移除重建，焦点和输入连接丢失；键盘关闭后布局又切回，滚动位置和展开状态也可能回到先前位置。

宽屏的 `expanded` 也依赖可被键盘压缩的高度，存在同类风险。短横屏另有空间问题：顶部照片工作台、材料栏和底部导航继续占据大量高度，键盘打开后输入区域可能被挤出视口。

旧安装包在相同回归测试中明确失败，截图显示键盘已关闭，界面跳回放大机参数列表顶部。初期测试定位、无障碍缓存和关闭动画等待问题单独保留，不当作产品缺陷证据；有效旧版红测为 `.tmp/libraw-upgrade/keyboard-before-final-test/`。

## 修改

- 新增 `EditorWindowLayout`，从应用窗口尺寸选择横竖屏和宽屏布局，和受键盘影响的内容高度分离。API 30 以上使用当前应用窗口 metrics；API 26–29 使用兼容显示尺寸。真正的窗口尺寸、方向和密度改变仍重新计算，不永久锁定首次布局。
- 主 Activity 明确使用 `adjustResize`，内容区沿用 `imePadding`。键盘只影响控件的可用空间，不再重建参数页。
- 输入期间暂时隐藏照片工作台、底部导航及宽屏材料信息，为文本输入留出空间；参数控件保持相同组成路径，滚动位置和展开状态继续保留。
- 手机上下调整区在输入时扩大参数面板；不改写用户选择的预览/参数比例，收起键盘后恢复。

没有修改日期文字、拍摄数据的存储格式或渲染参数，也没有修改胶片引擎、RAW 解码、图像处理和导出算法。

## 验证

使用 API 37 x86_64 模拟器的真实 Gboard，测试打开日期文字、等待完整键盘动画、连续改字、切换拍摄数据输入框、渲染完成、Back 收键盘后仍可访问放印输入框，以及两项文本写入编辑记录。测试清除无障碍缓存，并等待输入法关闭动画，避免把视口外控件误判为离开页面。

键盘由真实输入框点击触发，文本通过无障碍 `ACTION_SET_TEXT` 注入，Back 使用真实按键事件；不是逐个点击 Gboard 按键或候选词的输入法兼容测试。

测试尺寸为手机竖屏 1080×2400 @420dpi、短横屏 2400×1080 @420dpi、宽屏 2560×1600 @320dpi。最终结果和截图分别保存于 `.tmp/libraw-upgrade/keyboard-final-*` 与 `.tmp/keyboard-validation-final/`。完成后恢复模拟器原始尺寸、密度和外接键盘时的输入法显示设置。

最终三种配置均通过，共 3 条真实键盘回归；另 5 组、5 条编辑器回归全部通过，含 CineStill 布局、曲线、放大机、预设和交互采样。保留截图核对了输入框、键盘空间和关闭后的恢复状态。预览三例像素摘要保持，中性、旧色调和曲线分别约 11.37、24.36、32.33 ms，采样均无 GC。选片计时有环境波动，不能由一次采样推断所有交互性能不变。

追加相邻旧新版交互采样，12 次选片端到端中位数为 316.02→323.01 ms，主线程中位数 3.53→3.60 ms；三例预览像素摘要保持。该采样不足以证明所有性能完全相同，也不将约 2% 的选片波动解释为确定回归。完整证据为 `.tmp/keyboard-validation-final/verification.json`。

常规编辑回归覆盖 CineStill 控件、曲线、放大机、预设布局和预览/选片性能采样。最终包与修复前包的全部 198 项原生库和引擎资源逐字节一致；测试宿主的原生库和资源与 Release 相同，UI 使用相同源码的 Debug 构建。不能声称 Debug 与 Release 的 DEX 完全相同。

本次仍为 0.1.6 / code 7，V1/V2/V3 原更新证书，双 ABI。最终 APK 为 58,396,737 字节，SHA-256 `1b1de77320321035776add415d75f4d658c36854c762eec73103778b478bd8a8`。本地归档为 `app/release/v0.1.6-keyboard-fix/Theia-v0.1.6-keyboard-fix.apk`。

验证范围不包含厂商真机输入法、API 26–29 运行、多窗口拖动过程中持续输入和中文候选组合输入。其余开发计划和 ARM 全尺寸导出验收保持原状态；本次不发布 Release。
